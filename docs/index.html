Python expense tracker

Make sense of your spending, one expense at a time.

ExpenseIQ is a lightweight command-line application for recording expenses and exploring where your money goes. Your data stays in a local JSON file.

This page documents the Python application; expense tracking runs in your terminal.

ExpenseIQ · example workflow

01 / RECORD

$ python -m expenseiq.cli add \
--amount 12.50 --category Food \
--date 2026-10-28 --description "Lunch"

Added expense 1

02 / REVIEW

$ python -m expenseiq.cli list

1: 2026-10-28 | Food | 12.50 | Lunch

Saved locally to expenses.json

What it does

The essentials, thoughtfully covered.

ExpenseIQ combines everyday expense management with small, focused analytics functions.

＋

Record & manage

Add, list, update, and delete expenses from the command line. Each record has an amount, category, date, and description.

✓

Validate entries

Require positive, finite amounts, valid YYYY-MM-DD dates, and nonblank category and description fields.

▤

Keep data locally

Save changes to a JSON file. Choose the default expenses.json or supply a path with --file.

↗

Explore spending

Use Python functions to calculate totals, category breakdowns, the top category, and a structured summary.

Get started

Ready in a few commands.

Clone the project, install its test dependency, and run the Python CLI from the repository root. The application itself uses Python’s standard library.

Use Python 3.10 or newer. Dates use YYYY-MM-DD; amounts must be greater than zero.

Read the README ↗
01

Install

git clone https://github.com/BEH-77/ExpenseIQ.git
cd ExpenseIQ
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
02

Run the tracker

python -m expenseiq.cli add --amount 12.50 --category Food --date 2026-10-28 --description "Lunch"
python -m expenseiq.cli list

Use python -m expenseiq.cli --file my-expenses.json list for a different file.

03

Run the tests

python -m pytest -v
